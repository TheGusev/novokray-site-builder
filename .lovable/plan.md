## Показ цены на шаге 3 формы

### 1. Новый файл `src/data/leadPricing.ts`

Карта «вредитель + объект → цена от». Используем те же id что в `LeadForm` (`PESTS.id`, `OBJECTS.id`).

```ts
export const PRICING: Record<string, Record<string, number>> = {
  "Клопы":        { "Студия":1700, "1-комн. квартира":1900, "2-комн. квартира":2400, "3-комн. квартира":2900, "4+ комн. квартира":3500, "Частный дом":3900, "Дача":3500, ... },
  "Тараканы":     { ... },
  "Грызуны":      { ... },
  ...
};
export function getLeadPrice(pest: string, object: string): number | null { ... }
```

Заполняем по существующему прайсу `src/data/services.ts` (клопы 1900/2400/2900, тараканы аналогично, грызуны от 1500, осы от 2500, плесень от 1800, озонирование от 1500, сушка от 3000, участок/борщевик от 2500, и т.д.). Для пары без чёткой цены (например «Клопы · Участок») возвращаем `null` — тогда показываем «Рассчитаем по телефону».

### 2. `LeadForm.tsx` — карточка цены на шаге 3

В шаге 3 над «Ваш выбор» (или рядом) добавляем компактный блок:

- Если цена есть:
  - крупно: «от {price} ₽»
  - подпись: «Предварительная цена. Точная — после бесплатного осмотра.»
- Если цены нет:
  - «Рассчитаем за 5 минут по телефону» + «Бесплатный осмотр, цена фиксируется в договоре.»

Стиль: rounded-xl, `bg-cta-gradient/10` или `bg-secondary`, акцентная цена `text-primary` font-display.

В сводке «Ваш выбор · Клопы · 2-комн. квартира» оставляем как есть, кнопку «Изменить» оставляем.

Текст в submit-кнопке меняем на «Заказать за {price} ₽» когда цена известна, иначе оставляем «Отправить заявку».

### 3. Что не трогаем

- Шаги 1 и 2, прогресс-бар, валидация, согласие, телефон, toast — без изменений.
- Никакого бэкенда: цена — статика в `leadPricing.ts`.
- Страница `/price` и другие компоненты — не трогаем.
