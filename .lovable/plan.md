### 2) Подзаголовок: «бегущая строка» по словам + паузы между предложениями
Переписываю `src/components/site/WaveSentences.tsx`:
- Разбиваю текст на предложения, каждое предложение — на слова.
- Слова появляются последовательно: всплытие (`opacity 0→1`, `translate-y 6px → 0`, blur 4→0) длительностью ~380 мс, шаг между словами **~90 мс**.
- Между предложениями добавляю явную **паузу 700 мс** (накопленная задержка сдвигается на 700 мс перед первым словом следующего предложения).
- Цветовая «волна» в палитре заголовка по уже появившимся словам сохраняется (`WaveText` внутри каждого слова, общий счётчик символов для непрерывности волны через все слова).
- `aria-label` на корне + `sr-only` полный текст — для SEO и скринридеров.
- `prefers-reduced-motion`: все слова появляются сразу, волна отключена (уже глобально).

CSS keyframe `wave-sentence-in` в `src/styles.css` переименую/переиспользую под слова (`wave-word-in`) с blur и плавным подъёмом.
