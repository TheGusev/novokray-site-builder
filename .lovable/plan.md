## Цель

Наполнить все страницы сайта «Дез-Федерация.ру» развёрнутым продающим контентом и сгенерировать реалистичные фотографии под каждый блок и каждую услугу. Никаких эмодзи и «ИИ-плашек» — только живые фото, иконки Lucide и плотный экспертный текст.

## Технические задачи

1. **Генерация изображений** — последовательно (rate limits на генерации), батчами по 4–6 параллельно.
2. **Externalize** — `lovable-assets create --file ...` для каждого `.jpg`, сохранение `.asset.json` рядом, удаление оригинала.
3. **Обновить `src/data/services.ts`** — добавить поле `image: string` (url из `.asset.json`).
4. **Обновить `src/data/blog.ts`** — добавить поле `cover: string`.
5. **Создать компоненты:**
   - `src/components/site/Hero.tsx` — переиспользуемый геро с фото.
   - `src/components/site/PhotoGallery.tsx`.
   - `src/components/site/TeamGrid.tsx`.
   - `src/components/site/ReviewsGrid.tsx` (с фото авторов).
   - `src/components/site/PriceTable.tsx`.
   - `src/components/site/TimelineHistory.tsx`.
6. **Переписать страницы:** `index.tsx`, `services.index.tsx`, `services.$slug.tsx`, `o-kompanii.tsx`, `contacts.tsx`, `price.tsx`, `garantii.tsx`, `faq.tsx`, `category.dezinfekciya-novosibirsk.tsx`, `blog.index.tsx`, `blog.$slug.tsx`.
7. **Lazy-loading** для всех `<img>` (`loading="lazy"`, `decoding="async"`), для hero — `loading="eager"` + `fetchpriority="high"`.
8. **Alt-тексты** — осмысленные, с ключевыми словами Новосибирска.
9. **og:image** на каждой leaf-странице (геро-фото услуги/статьи).
10. **Проверка билда** после массовых правок.

## Что НЕ делаю

- Не подключаю Lovable Cloud / реальный приём заявок.
- Не меняю набор из 13 услуг.
- Не генерирую видео (только статичные фото).
- Не использую стоковые URL — все фото генерируются под бренд.
