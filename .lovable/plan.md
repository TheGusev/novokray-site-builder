
# Сайт «Дез-Федерация.ру» — план реализации

Цель: построить продающий SEO-сайт №1 в Новосибирске для услуг дезинфекции, дератизации, обработки от вредителей, плесени, озонирования и сушки после затоплений. Полная техническая SEO/GEO-архитектура по ТЗ OwnDev Site Formula PRO.

## 1. Архитектура и роутинг (TanStack Start, file-based)

```
/                                  Главная (hub, бренд + услуги + CTA)
/services                          Каталог всех 13 услуг (hub)
/services/$slug                    Отдельная страница каждой услуги
/category/dezinfekciya-novosibirsk Категория-хаб (коммерч.)
/o-kompanii                        О компании
/contacts                          Контакты + LocalBusiness JSON-LD
/price                             Прайс-лист
/garantii                          Гарантии и сертификаты
/blog                              Блог (список с пагинацией)
/blog/$slug                        Статья
/faq                               FAQ (FAQPage schema)
/api/sitemap[.]xml                 Динамический sitemap.xml
/robots.txt, /llms.txt, /.well-known/ai  Статика в public/
```

Приоритетные услуги (по запросу пользователя — выше первого экрана):
1. Уничтожение клопов
2. Уничтожение тараканов
3. Обработка участков от вредителей (комары, клещи, муравьи)
4. Обработка от плесени и грибка
5. Озонирование помещений
6. Сушка и обработка после затоплений

Плюс из ТЗ: дезинфекция, дератизация (мыши/крысы), уничтожение блох, ос, борщевика, фумигация, дезодорация.

## 2. SEO/GEO — обязательные элементы (из ТЗ)

- `head()` per route: title, description, og:*, twitter:*, canonical (relative path), hreflang ru.
- JSON-LD `@graph` в `__root.tsx`: Organization + WebSite + LocalBusiness (Новосибирск, координаты, телефон, email).
- На страницах услуг — Service + BreadcrumbList + FAQPage JSON-LD.
- На блог-статьях — Article + BreadcrumbList.
- **Первый параграф** каждой ключевой страницы — прямой 40–80-словный ответ (для AI-цитирования).
- **CTA выше первого экрана** на каждой коммерч. странице (форма «Заказать выезд» + телефон).
- FAQ ≥ 5 вопросов на каждой странице услуги с микроразметкой.
- `robots.txt` с явными правилами для GPTBot, ClaudeBot, PerplexityBot, YandexGPT, Anthropic-AI, Claude-Web.
- `llms.txt` в корне.
- `/.well-known/ai` JSON-policy.
- `sitemap.xml` динамический, только indexable страницы.
- `noindex` на /admin, /cart, /thanks (через `meta robots`).
- Canonical без UTM, относительные пути.

## 3. Перелинковка

- Хедер: главное меню (Услуги ▾ с превью 6 приоритетных, О компании, Цены, Блог, Контакты) + телефон + CTA-кнопка.
- Hub `/services` ссылается на все 13 услуг.
- Каждая страница услуги: блок «Смежные услуги» (4 карточки), хлебные крошки, ссылки на блог по теме, ссылка на категорию.
- Футер: 4 колонки — Услуги (все 13), Компания, Полезное (блог, FAQ, гарантии), Контакты + соцсети + копирайт.
- Sticky bottom-CTA на мобильных (звонок / заказать).

## 4. Контент посадочной страницы услуги (шаблон)

1. Hero: H1 «<Услуга> в Новосибирске», подзаголовок-ответ 40–80 слов, CTA «Вызвать мастера» + цена «от ___ ₽» + телефон.
2. «Признаки заражения» / проблема — иконки + текст.
3. «Как мы работаем» — 4 шага.
4. «Используемые препараты» / технология (озон / горячий туман / барьерная обработка).
5. Цены — таблица (квартиры, дома, офисы, участки).
6. Гарантии — карточки (договор, чек, сертификаты, бесплатная повторка).
7. Отзывы — 3-4 карточки.
8. FAQ — accordion, 6-8 вопросов.
9. Финальная CTA-форма (имя, телефон, объект, дата) + JSON-LD `ContactPoint`.
10. Блок «Смежные услуги» + ссылки на статьи блога.

## 5. Пагинация

- `/blog?page=N` через TanStack search params (`validateSearch` + `fallback`), кнопки prev/next + `<link rel="prev/next">` в head.
- 9 статей на страницу.

## 6. Дизайн-система

Тон: профессиональный, чистый, доверительный (медицинский / технический). Не «дешёвый клин-сервис».

- Цвета (oklch в `src/styles.css`):
  - `--primary`: глубокий бирюзово-синий (медицина, чистота) ~ `oklch(0.55 0.15 220)`
  - `--accent`: тёплый оранжево-красный для CTA `oklch(0.68 0.20 35)` (срочность)
  - Нейтрали: белый фон, графитовый текст
  - Градиент hero: `--gradient-hero` от primary к темно-синему
  - `--shadow-elegant`, `--shadow-card`
- Шрифты: Inter (body) + Manrope (heading) через Google Fonts в `__root.tsx`.
- Радиусы `--radius: 0.75rem`, мягкие тени, subtle micro-animations (tw-animate-css).
- Hero-фото генерируем (мастер в форме обрабатывает помещение).
- Иконки услуг — Lucide + цветные акценты.
- Полная адаптивность mobile-first.

## 7. Технические детали (TanStack Start)

- Route files в `src/routes/` с дот-нотацией (`services.$slug.tsx`, `blog.$slug.tsx`).
- Контент услуг/статей — типизированный массив в `src/data/services.ts` и `src/data/blog.ts` (источник истины для роутов, sitemap и навигации).
- `__root.tsx` — общие meta-defaults, шапка/футер, JSON-LD Organization/WebSite/LocalBusiness, шрифты.
- Sticky header + sticky mobile CTA через клиентский компонент.
- Форма заявки — клиентская, валидация zod, mock submit (без бэка — Lovable Cloud не запрошен), toast «Заявка принята».
- Sitemap: `src/routes/sitemap[.]xml.ts` динамически собирает из `services.ts` и `blog.ts`.
- `public/robots.txt`, `public/llms.txt`, `public/.well-known/ai` — статичные файлы по ТЗ.
- BASE_URL = `https://dez-federation.ru` (домен из ТЗ).

## 8. Что НЕ входит в эту итерацию

- Реальная отправка заявок (нет бэка — нужен Lovable Cloud, добавим по запросу).
- Личный кабинет, корзина, оплата.
- Реальные фото объектов (используем генерации + Lucide иконки).
- Полнотекстовый поиск по блогу.
