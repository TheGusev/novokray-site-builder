## 1. Корень проблемы с буквой «ы»

`WaveText` оборачивает КАЖДУЮ букву в отдельный `<span class="wave-char">`. Браузер считает каждую букву отдельным «токеном» и может перенести последнюю букву слова на новую строку. Поэтому в «службы» буква «ы» уезжает вниз.

### Фикс — `src/components/site/WaveText.tsx`

Разбивать не по буквам, а сначала по словам, и каждое слово оборачивать в `inline-block` контейнер. Внутри слова — буквы. Переносы возможны только между словами.

```tsx
const words = text.split(" ");
// для каждого слова: <span className="wave-word inline-block whitespace-nowrap">
//   {[...word].map((ch, j) => <span className="wave-char">{ch}</span>)}
// </span>{i < words.length-1 ? " " : null}
```

`aria-label` остаётся = полному тексту. Анимационный `animation-delay` считаем по глобальному индексу буквы, чтобы волна не сбивалась.

Добавить в `src/styles.css` к `.wave-text`:
- `text-wrap: balance;` (для крупных h1).
- В `.wave-text` — `hyphens: manual; word-break: normal; overflow-wrap: normal;` (страховка).

## 3. Ревизия текстов (грамматика, падежи, глаголы)

Прохожу основные пользовательские строки и привожу к единому тону «мы делаем X». Файлы под чистку:

- `src/data/site.ts` — название, слоганы, телефон-подпись.
- `src/data/services.ts` — `title`, `h1`, `metaTitle`, `metaDescription`, `lead`, `problems[]`, `steps[]`, `tech[]`, `prices[]`, `faq[]` для всех 13 услуг.
- `src/data/blog.ts` — заголовки и описания статей.
- Шапки/футер: `Header.tsx`, `Footer.tsx`, `TrustStrip.tsx`, `FAQ.tsx`.
- Главная `routes/index.tsx` — все секции (hero, преимущества, услуги, отзывы, гарантии, география, CTA).
- Прочие страницы списком: `services.index.tsx`, `price.tsx`, `garantii.tsx`, `faq.tsx`, `contacts.tsx`, `o-kompanii.tsx`, `category.dezinfekciya-novosibirsk.tsx`.
- Форма: `LeadForm.tsx` (плейсхолдеры, кнопки, подписи).

Что проверяю:
- Падежи («от 1 900 ₽», «в Новосибирске», «по договору»).
- Согласование числительных («1 час», «2 часа», «5 часов»; «12 месяцев», «1,5 месяца»).
- Глаголы единым лицом — везде «мы»/«работаем»/«даём гарантию».
- Кавычки «ёлочки», тире — длинное «—» с неразрывными пробелами `&nbsp;—&nbsp;` в коротких фразах.
- Буква «ё» там, где она важна для смысла («все/всё», «осмотр»).
- Лишние пробелы, двойные точки, опечатки.
- Единообразие («тел.» / «телефон», «руб.» / «₽», «м²»).

## 4. Что НЕ делаем

- Не переписываем дизайн и не трогаем структуру страниц.
- Не меняем routes/файлы данных по смыслу — только текст и переносы.
- Не трогаем формы/логику, селекты, цены — только подписи и плейсхолдеры.
- Без бэкенда.
