## Задача

В конструкторе договора (`/dogovor/zapolnit`) заменить одиночный `<select>` вредителя в блоке услуг на **мультиселект** — можно отметить нескольких вредителей сразу, а система автоматически развернёт их в отдельные блоки обработки (у каждого своя степень, работы, препараты, гарантия).

## Файл

`src/routes/dogovor.zapolnit.tsx` — единственный правочный файл. Каталог, PDF-билдер и валидация не меняются (они уже работают поблочно).

## UX

Вместо селекта в шапке блока «1. Блок обработки» — компактный **чип-мультиселект**:

```text
ВРЕДИТЕЛИ (можно выбрать несколько)
[✓ Клопы] [ Тараканы] [ Блохи] [✓ Комары (участок)] [ Клещи] …
```

- Клик по чипу с «−» вредителем → создаётся новый блок с дефолтами (степень «1», без работ, препараты из каталога).
- Повторный клик по активному чипу → удаляет соответствующий блок (с подтверждением, если в нём уже отмечены работы).
- Мультиселект-панель показывается **один раз наверху** секции «3. Услуги», а ниже рендерятся сами блоки — по одному на каждого выбранного вредителя (текущая логика `blocks.map`).
- Внутри каждого блока поле «Вредитель» убирается (тип уже понятен из заголовка блока), остаётся степень / гарантия / препараты / работы — как сейчас.
- Кнопка «+ Добавить блок обработки» удаляется (её роль берёт на себя мультиселект). Если пользователь хочет **два блока одного вредителя** (например, две квартиры от клопов) — оставляю маленькую ссылку «Добавить ещё один блок для этого вредителя» в шапке уже существующего блока.

## Технические детали

- `blocks: UiBlock[]` остаётся как есть; ключом соответствия «чип ↔ блок» служит `pest` внутри блока.
- Новый компонент `<PestMultiSelect selected={Set<pestKey>} onToggle={...} />` рендерит чипы по `CATALOG`, outdoor-вредители помечаются мини-бейджем «участок».
- `onToggle(pestKey)`:
  - если ключа нет в `blocks` → `setBlocks([...blocks, makeBlock(pestKey)])`;
  - если есть и в блоке нет отмеченных работ → удалить блок;
  - если есть и работы отмечены → `confirm("Удалить блок «X»? Все отмеченные работы будут потеряны")`.
- Валидация: если выбрано 0 вредителей — показывать инлайновую ошибку «Выберите хотя бы одного вредителя», кнопка PDF блокируется (переиспользую текущий `hasBlockingErrors`).
