## Что не так сейчас

`src/routes/dogovor.zapolnit.tsx`:

1. `togglePest(key)` при отключении чипа **удаляет все блоки** с этим `pestKey` (включая дубликаты через «+ ещё «Клопы»») и **безвозвратно теряет** отмеченные работы, препараты, ручные цены и override барьера. Повторный клик по чипу создаёт свежий `makeBlock` — состояние не восстанавливается.
2. `selectedPests = new Set(blocks.map(b => b.pestKey))` схлопывает дубликаты: у двух блоков «Клопы» чип один, и он снимает оба сразу.
3. `blockSum` в `buildPdf.ts` уже суммирует по `lines` (мультипликатор и barrier override уже применены в `buildBlockLines`), поэтому мультивредитель считается правильно **сейчас**, но после правки состояния мы должны это гарантированно не сломать: восстановленный из «кладбища» блок обязан пересобирать `lines` через `buildBlockLines` → `toContractBlock`, а не восстанавливать старую сумму.

## Что делаю (только `src/routes/dogovor.zapolnit.tsx`)

### 1. Кэш снятых блоков вместо удаления

Добавляю параллельное состояние:

```ts
const [graveyard, setGraveyard] = useState<Record<string, UiBlock[]>>({});
```

`togglePest(pestKey)`:

- **если блока нет** → сначала пробуем достать из `graveyard[pestKey]` (последний снятый) и вернуть его в `blocks`; если нет — `makeBlock(pestKey)`;
- **если блок(и) есть** → снимаем **все** с этим `pestKey` (текущее поведение чипа), но перед удалением кладём их в `graveyard[pestKey]` (пуш в массив). Подтверждение показываем только если хоть в одном блоке есть работы/барьер.

`removeBlock(id)` (крестик внутри блока) → тоже кладёт в `graveyard[b.pestKey]`, чтобы «нажал крестик — снова выбрал чип» вернуло состояние.

`duplicateBlock(pestKey)` не трогаем — он для намеренного второго блока.

Это решает п.1: препараты, работы, ручные цены и `barrierPriceOverride` переживают toggle.

### 2. Дубликаты в чипе

`selectedPests` оставляю как `Set` (визуально «активно/нет»), но добавляю рядом счётчик:

```tsx
<span className="badge">×{count}</span>  // только если count > 1
```

Клик по чипу с `count > 1` перед снятием подтверждает: «У вас {count} блоков «X». Скрыть все?». В `graveyard` кладём массив, восстановление возвращает **последний** снятый (по одному на клик), остальные остаются в кладбище — повторный клик по чипу поднимет следующий.

### 3. Пересчёт итогов

- Оставляю единый путь: `contractBlocks = blocks.map(toContractBlock)` → `totalSum(contractBlocks)`. Ничего в `buildPdf.ts` не меняю.
- В сайдбар-итог добавляю строку `Итого по {pest.name} · блок {n}` когда один и тот же вредитель встречается несколько раз — сейчас они показываются подряд без нумерации и сливаются визуально.
- Убеждаюсь, что `blockSum(cb)` рядом с блоком уже учитывает `manual` и `barrierPriceOverride` (учитывает — они уходят в `lines` внутри `buildBlockLines`).

### 4. Мелочи

- Валидация уже блокирует PDF при `totalErrors > 0` — не меняю.
