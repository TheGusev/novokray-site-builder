## Что меняем

Сейчас услуга в конструкторе договора — это плоская строка «Вредитель × Объект × Цена». Этого мало: цена зависит от **степени заражения** и от **набора конкретных работ** (пролив кровати, шкафа, плинтусов, дверных коробок, кухонного гарнитура и т.п.). Перестраиваем модель так, чтобы мастер собирал смету как конструктор, а в договоре всё отображалось построчно.

## Модель данных (новый файл `src/data/treatmentCatalog.ts`)

```text
Pest (вредитель)
 ├── infestationLevels: [1, "2-3", "4-5"]   // множители ×1 / ×1.5 / ×2
 ├── methodNote: текст методики (для договора)
 ├── defaultWarrantyByLevel: { "1": 90, "2-3": 60, "4-5": 30 }  // дни
 ├── defaultPreparations: ["Лямбда-зона", "Дельта-зона", ...]
 └── elements: TreatmentElement[]            // что можно «пролить/обработать»
       ├── id, name, unit (шт / м.п. / комплект)
       ├── basePrice (₽ за единицу при степени 1)
       └── pestSpecific?: true               // показывать только для этого вредителя
```

**Пресеты по вредителю (базовые цены за единицу, степень 1):**

| Вредитель | Элементы |
|---|---|
| Клопы | Пролив кровати — 600/шт · Пролив дивана — 700/шт · Пролив шкафа — 500/шт · Плинтусы (напольные/потолочные) — 50/м.п. · Дверные коробки — 200/шт · Розетки/выключатели — 80/шт · Барьерная защита периметра — 1500/комплект |
| Тараканы | Кухонный гарнитур — 1500/комплект · Пролив холодильника (за/под) — 400/шт · Раковина/сантехузел — 500/шт · Плинтусы — 50/м.п. · Вентиляция/короба — 300/шт · Гель-приманка — 400/комплект · Барьер — 1500 |
| Блохи | Пол (за м²) — 40/м² · Плинтусы — 50/м.п. · Ковры/мягкая мебель — 500/шт · Барьер — 1500 |
| Муравьи | Пути миграции — 300/м.п. · Гнёзда (локально) — 500/шт · Гель — 400/комплект |
| Грызуны | Раскладка приманки — 200/точка · Клеевые площадки — 150/шт · Норы (заделка+яд) — 400/шт |
| Осы/шершни | Гнездо до 20 см — 2000 · Гнездо 20-50 см — 3500 · Высотная работа +1500 |
| Плесень | Обработка стен — 250/м² · Антисептирование швов — 100/м.п. · Озонирование — 1500/комплект |

(Цены — «разумные базовые», правятся в одном файле без касания UI.)

**Степень заражения → множитель и срок гарантии:**

```text
1 балл     → ×1.0   · гарантия 90 дней
2-3 балла  → ×1.5   · гарантия 60 дней
4-5 баллов → ×2.0   · гарантия 30 дней
```

Гарантия предлагается автоматически по выбранной степени, но мастер может переопределить.

## UI конструктора (раздел «3. Услуги»)

Каждая «услуга» становится **блоком обработки одного вредителя**:

```text
┌─ Блок 1 ────────────────────────────────────────────┐
│ Вредитель: [Клопы ▼]   Степень: [1 / 2-3 / 4-5]    │
│ Гарантия:  [60 дн ▼]   (по умолчанию из степени)    │
│ Препараты: [☑ Лямбда-зона] [☑ Гет] [+ свой]        │
│ ─ Работы: ─────────────────────────────────────────│
│ [☑] Пролив кровати          кол-во [2]  =  1 800 ₽ │
│ [☑] Пролив шкафа            кол-во [3]  =  2 250 ₽ │
│ [☑] Плинтусы (м.п.)         кол-во [12] =    900 ₽ │
│ [☐] Дверные коробки         кол-во [—]             │
│ [+ Своя работа]                                     │
│ ─ Доп. опции: ─────────────────────────────────────│
│ [☑] Барьерная защита периметра          + 2 250 ₽  │
│                                                     │
│ Итого по блоку: 7 200 ₽  (×1.5 за степень 2-3)     │
│ [+ Добавить вредителя]   [🗑 Удалить блок]         │
└─────────────────────────────────────────────────────┘
```

- При смене вредителя список «Работ» перерисовывается из каталога.
- При смене степени все цены в блоке мгновенно пересчитываются (множитель ×1/1.5/2) и подсказывается новый срок гарантии.
- Чекбокс «Барьерная защита» = отдельная позиция в смете с собственной ценой.
- Можно добавить произвольную работу руками (поле «своя работа» — name + qty + price).

Правая колонка-итог остаётся, но теперь показывает группировку по блокам и общую сумму.

## Отображение в PDF (`buildPdf.ts`)

Раздел «2. Перечень услуг» становится сгруппированной таблицей:

```text
Блок 1. Клопы · степень заражения 2-3 (коэффициент ×1.5)
Препараты: Лямбда-зона, Гет. Методика: …
№  Наименование                          Кол  Цена   Сумма
1  Пролив кровати                          2    900   1 800
2  Пролив шкафа                            3    750   2 250
3  Плинтусы напольные (м.п.)              12     75     900
4  Барьерная защита периметра              1  2 250   2 250
                                       Итого по блоку: 7 200 ₽
                                       Гарантия: 60 дн.

Блок 2. Тараканы · степень 1 (×1.0)
…

ИТОГО ПО ДОГОВОРУ: 12 400 ₽ (Двенадцать тысяч четыреста рублей 00 копеек)
```

В разделе «3. Гарантийные обязательства» гарантия указывается **по каждому блоку отдельно** (минимальная — общая по договору), плюс перечисляются применённые препараты.

## Технические изменения

**Новые файлы:**
- `src/data/treatmentCatalog.ts` — каталог вредителей, элементов работ, базовых цен, методик, препаратов, множителей степени, сроков гарантии.

**Изменения:**
- `src/lib/dogovor/buildPdf.ts` — тип `ContractData.services` становится `ContractBlock[]`, где блок = `{ pest, level, multiplier, warrantyDays, preparations[], lines: ServiceLine[], note }`. Рендер таблицы группирует строки по блокам и печатает подзаголовок + итог блока.
- `src/routes/dogovor.zapolnit.tsx` — раздел «3. Услуги» переписывается под блоки (state — массив блоков, внутри блока — массив выбранных элементов). Поле «Гарантия» из раздела 4 убираем (теперь на блок); «Способ оплаты» и «Подпись мастера» остаются.
- Правый sidebar-итог — рендерит группы.

**Без изменений:** заказчик (физ/юр), реквизиты, подпись, генерация номера, шрифты.

**Не используем:** Lovable Cloud (всё клиентское, как сейчас). Если позже захотите редактировать прайс из админки — вынесем каталог в БД отдельной задачей.

## Что НЕ делаем в этой итерации

- Не добавляем загрузку каталога с сервера (правки цен — через файл `treatmentCatalog.ts`).
- Не трогаем основной калькулятор лидов на главной — у него другой контекст («от такой-то суммы»).
- Не добавляем сохранение черновиков договоров.
