## Что нужно подключить (требует build mode)

Один файл — `src/data/images.ts`:
1. Добавить импорты 12 `blog-*` и 6 `gallery-*` файлов.
2. `GALLERY` → массив из 6 новых `gallery-1..6`.
3. `BLOG_COVERS` → каждый slug ссылается на свой `blog-*`, а не переиспользует `svc-*`.

Никакие другие файлы не трогаются — компоненты уже читают `BLOG_COVERS` и `GALLERY` из этого модуля.

Скажите «Выполняй» / переключите в build mode — подключу импорты и всё заработает.
