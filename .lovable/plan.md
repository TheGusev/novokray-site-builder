- Добавить чекбокс/переключатель «Ручная цена» на позицию: когда включён — множитель степени заражения (×1 / ×1.5 / ×2) к этой строке не применяется (в расчёте берётся ровно введённая мастером сумма × кол-во). Индикатор «(без множителя степени)» рядом со строкой.
- Для «своих работ» (custom rows) — то же поле цены (уже есть), унифицировать UI с обычными позициями.
- В «Барьерной защите» разрешить редактировать цену вручную (сейчас фикс).
- Итог по блоку и общий итог пересчитываются реактивно (уже через `useMemo`).
- В PDF (`buildPdf.ts`): для строк с ручной ценой в колонке «Цена» показывать введённую цифру без пометки множителя; в описании блока добавить сноску «* — цена согласована мастером на месте» если есть хотя бы одна ручная строка.
- Валидация (`validateBlock`): цена > 0, ≤ 1 000 000 ₽/ед.; при 0 — блокирующая ошибка.
