# Убрать разметку рейтинга и отзывов из кода страниц

Рейтинг 4,9 и 1268 отзывов остаются видимыми на сайте как есть. Из служебной
разметки для поисковиков рейтинг и отзывы убираются полностью — до тех пор,
пока не появятся подтверждённые отзывы с Яндекс.Карт или 2ГИС со ссылкой на
профиль. Данные об организации (название, адрес, телефон, часы работы,
зона выезда, лицензия) остаются в разметке без изменений.

## Что меняется

1. **Главная страница**: из служебной разметки удаляется блок с пятью
   отзывами и оценками. Сам блок отзывов на экране остаётся.
2. **Страница «Контакты»**: из разметки организации удаляется средняя оценка
   и число отзывов.
3. **Все страницы сайта**: общая разметка организации перестаёт добавлять
   оценку — остаётся «безопасный» набор данных об организации.
4. **Описание главной страницы для поиска** переписывается без фразы
   «Рейтинг 4.9 из 5 (1268 отзывов)» — вместо неё преимущество, которое можно
   подтвердить: лицензия Роспотребнадзора и гарантия по договору.
5. **Файл-описание сайта для ИИ-поиска** (`llms-full.txt`): строка с рейтингом
   убирается.
6. **Автопроверка**: добавляется тест, который валит сборку, если в разметке
   любой страницы снова появится оценка или отзыв. Так значение не вернётся
   случайно при следующих правках.

## Технические детали

- `src/lib/orgSchema.ts`: убрать опцию `withRating` и ветку с
  `aggregateRating`; `src/routes/__root.tsx` — снять `withRating: true`.
- `src/routes/contacts.tsx`: удалить узел `aggregateRating` из
  `LocalBusiness`.
- `src/routes/index.tsx`: удалить JSON-LD-узел `LocalBusiness` с массивом
  `review`/`reviewRating` (визуальный массив `REVIEWS` и секция отзывов
  остаются); переписать `meta description`.
- `src/data/site.ts`: `SITE.rating` сохраняется — на нём держатся видимые
  цифры в `StatsRow.tsx`, `Footer.tsx` и секции отзывов; добавить комментарий,
  что значение только для отображения и в JSON-LD не попадает.
- `public/llms-full.txt`: удалить строку «Рейтинг: 4.9 из 5 (1268 отзывов)».
- `src/lib/__tests__/headMarkup.test.ts`: проверка по всем маршрутам, что в
  JSON-LD нет `aggregateRating`, `Review`, `reviewRating`, `ratingValue`.
- Прогон: `bunx vitest run`, `bun scripts/check-static-schema.mjs`,
  `bun run check:links`.
- `AUDIT.md`: пункт 1 в списке «не выполнено» переводится в «закрыто»,
  оценка пересчитывается.
