# Договор: гарантия в месяцах, подписи на экране и печать

## Что меняется для пользователя

1. **Срок гарантии — в месяцах.** В блоке каждой обработки вместо «Гарантия (дней)» будет «Гарантия (мес.)». По степени заражения подставляются 3 / 2 / 1 месяца (сейчас 90 / 60 / 30 дней). Мастер может править значение вручную (1–36 мес.), валидация обновляется. В PDF пишется «гарантия 3 месяца» с правильным склонением (месяц / месяца / месяцев).

2. **Подпись пальцем или мышью прямо на экране.** Последний шаг перед скачиванием — «Подписание». Два поля рисования подряд: сначала мастер, затем клиент. Каждое поле — светлый холст с линией и подсказкой «Распишитесь здесь», кнопки «Очистить» и «Готово». Работает и на телефоне (палец), и на ПК (мышь). Подпись обрезается по краям, фон прозрачный, сохраняется как PNG.
   - Кнопка скачивания PDF остаётся доступной, но если подписей нет — предупреждение «Договор будет без подписей» (не блокирует).
   - Загрузка готового файла подписи остаётся как запасной вариант для мастера.

3. **Печать организации.** В блоке подписи Исполнителя рисуется наша круглая печать: по внешнему кругу «ООО САНИТАРНЫЕ РЕШЕНИЯ», по внутреннему — ИНН и ОГРН, в центре — «Новосибирск» и номер лицензии. Синий цвет, лёгкая прозрачность, печать частично перекрывает подпись мастера — как на живом документе. Данные берутся из единого источника реквизитов сайта, ничего не дублируется вручную.

## Технические детали

- `src/data/treatmentCatalog.ts`: `LEVEL_WARRANTY_DAYS` → `LEVEL_WARRANTY_MONTHS` (3 / 2 / 1). Тесты каталога обновляются под новое поле.
- `src/routes/dogovor.zapolnit.tsx`: поле блока `warrantyDays` → `warrantyMonths`; input, валидация (1–36) и подсказка; новый шаг «Подписание»; состояние `masterSignature` / `clientSignature` (PNG ArrayBuffer).
- Новый `src/components/dogovor/SignaturePad.tsx`: canvas с pointer-событиями, `touch-action: none`, масштабирование по `devicePixelRatio`, обрезка пустых полей, экспорт через `toBlob` → `arrayBuffer`.
- Новый `src/lib/dogovor/stamp.ts`: векторная отрисовка печати в pdf-lib (два круга, текст по дуге посимвольно с `rotate`, центральный блок), данные из `SITE.legal`.
- `src/lib/dogovor/buildPdf.ts`: `warrantyMonths` в типе и в разделе 3; `signaturePng` → `masterSignaturePng` + `clientSignaturePng`, обе врисовываются над своими линиями; вызов печати в колонке Исполнителя с проверкой, что она не залезает на реквизиты и футер.
- Склонение месяцев — небольшой плюрализатор рядом с `rubInWords`.
- Тесты: плюрализатор и маппинг «степень → месяцы»; `buildPdf` принимает обе подписи и корректно работает без них.

## Проверка

Генерирую договор с двумя обработками, обеими подписями и печатью, конвертирую страницы в изображения и просматриваю: подписи не наезжают на текст, печать читается и не перекрывает реквизиты, гарантия отображается в месяцах.
